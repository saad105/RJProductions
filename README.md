# Real Javeed Productions

Website for Real Javeed Productions: videography, photography, event coverage, brand media, websites and content creation.

**Capture · Create · Inspire**

## Run locally

Open `index.html` in a browser. No build step is needed.

## Structure

- `index.html` – page markup
- `styles.css` – black & gold theme, layout and animations
- `script.js` – navigation, scroll reveals, particles and the booking form
- `assets/` – logo, flyer and Instagram QR code
